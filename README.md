# Ход вперёд

Откройте сайт через HTTPS или локальный HTTP-сервер. Для входа, облачного профиля, отзывов и админ-панели требуется проект Supabase; собственный сервер приложения и сборка не нужны.

- index.html — отдельные разделы партий против движка, игры вдвоём, тактики, ежедневной задачи и обучения дебютам.
- game.html — Stockfish 19 с настраиваемым уровнем силы 0–20 либо два игрока за одним экраном; часы, выбор превращения и анализ партии.
- puzzles.html — тактические задачи и ежедневное испытание с локальной серией дней.
- lesson.html — теория перед каждым этапом; её можно пропустить и сразу перейти к практике.
- openings.html — интерактивные варианты дебютов с пошаговой доской и пояснениями.
- css/style.css — адаптивные стили, включая интерфейс для телефонов.
- js/main.js и js/openings.js — игровой прогресс с синхронизацией Supabase и локальным кэшем; js/supabaseClient.js — клиент Auth и базы данных; js/auth.js — обязательный вход и форма отзывов; js/admin.js — админ-панель.
- js/chess.js — сторонняя библиотека chess.js 0.10.3 (BSD-2-Clause), https://github.com/jhlywa/chess.js/tree/v0.10.3.

Победа над ботом или решение задачи открывает следующий этап своей дорожки; задачи и партии больше не блокируют друг друга. 12 этапов против ботов возрастают от Skill Level 0 до 20, а отдельные тактические задачи содержат собственные позиции и объяснения. При первом посещении показывается вводная теория с возможностью пропустить её. Достижения, прогресс, ежедневная серия, статистика и XP синхронизируются с Supabase и загружаются при входе. Старые отметки этапов переносятся на новый порядок автоматически. Онлайн-игра не предусмотрена.

Для Stockfish и одинакового хранения прогресса между страницами рекомендуется открыть сайт через любой статический HTTP(S)-хостинг или локальный сервер (например, `python -m http.server 8000`) и перейти на http://localhost:8000. Supabase используется как облачный бэкенд; отдельный сервер приложения не требуется. При открытии через file:// ограничения браузера могут отключить Worker и WebAssembly; тогда партия переключается на встроенный учебный бот, а интерфейс сообщает об этом. Поведение localStorage для file:// зависит от браузера. При недоступном хранилище приложение работает без постоянного сохранения.

## Stockfish.js

В комплект включена официальная браузерная сборка Stockfish.js 19.0.1 lite single-threaded и её WebAssembly-файл. Движок выполняется локально в Web Worker; выбор Skill Level от 0 до 20 управляет реальной сложностью Stockfish. По умолчанию движок загружается только при партии или запуске анализа. Для мобильных устройств используется меньшая глубина анализа.

Stockfish.js распространяется по GNU GPL v3. Полный текст лицензии находится в `js/vendor/stockfish.COPYING.txt`; соответствующий исходный проект и сведения о сборке: https://github.com/nmrugg/stockfish.js. WebAssembly-файл около 1.8 MB хранится локально и не скачивается со стороннего сервера при игре.

Оценки и классификация ходов — самостоятельный разбор на основе вычислений Stockfish, а не точная копия показателей какого-либо коммерческого сервиса. Анализ запускается вручную, ограничен первыми 120 полуходами и может занять заметное время на телефоне.

## 2D- и 3D-доска

В игре, задачах и учебнике дебютов можно переключать 2D- и 3D-доску в редакторе «Доска и фигуры». 3D-вид использует локальный Three.js, объёмные модели фигур, тени и анимацию ходов. В игре и задачах клики по 3D-доске используют те же шахматные правила; в учебнике дебютов 3D-доска синхронизируется с просмотром ходов. Выбранный режим сохраняется и применяется во всех трёх разделах. При недоступном WebGL остаётся 2D-доска.

## Настройка фигур

В игре, задачах и дебютах откройте редактор «Доска и фигуры». Доступны три формы (Классика, Королевские, Геометрия), четыре цветовых набора фигур, индивидуальный выбор цветов и палитры доски. Настройки сохраняются в localStorage и синхронизируются между разделами; фигуры отображаются в выбранном стиле как в 2D-, так и в 3D-режиме.

## Восстановление партии и проверки

Незавершённая партия автоматически сохраняется в этом браузере: позиция, история, режим, сложность, этап и состояние часов. После обновления она восстанавливается; время активного игрока продолжает идти, пока страница закрыта. «Новая игра» и завершение партии очищают сохранение. Для работы сохранений браузер должен разрешать localStorage.

Расчёт Stockfish выполняется в Web Worker. Если браузер не разрешает Worker или WebAssembly, используется встроенный учебный бот с явным уведомлением. Сброс или завершение партии отменяет текущий расчёт.

Регрессионные проверки без установки зависимостей: `node tests/regression.cjs`. Проверяются восстановление партии и часов, завершение при превращении, материал для мата при флаге, UCI-команды движка и отмена устаревшего Worker, кооперативный расчёт, синхронизация 3D и подсветка шаха. Проверки 3D используют настоящую геометрию с заглушкой WebGL-рендерера; они не заменяют визуальную проверку в браузере.

## Подключение Supabase

1. Создайте бесплатный проект Supabase. В `js/supabaseClient.js` укажите Project URL и Publishable key (`sb_publishable_...`; в старом интерфейсе — anon/public key). Это публичные клиентские значения. Никогда не помещайте `service_role` или secret key в файлы сайта.
2. В Supabase Dashboard откройте SQL Editor и выполните `supabase/schema.sql`, затем `supabase/admin_dashboard.sql`. Второй файл включает роли, закрытые проверки админ-панели, управление администраторами и аналитику посещений. При обновлении сайта SQL повторно выполнять не нужно.
3. В Authentication → URL Configuration добавьте адрес сайта и локальный адрес разработки, например `http://localhost:8000`. Оставьте включённым подтверждение email. В Authentication → Providers включите Email.
4. Зарегистрируйте свой аккаунт через сайт и подтвердите email. В SQL Editor выполните вручную, подставив именно свой подтверждённый email: `update public.profiles set role='super_admin' where email=lower('ВАШ_EMAIL');`. Проверьте, что изменена одна строка. Публичная регистрация всегда создаёт только роль `user`.
5. Опубликуйте сайт через HTTPS (GitHub Pages подходит), войдите с email и паролем и откройте `admin.html`. Только `admin` и `super_admin` получают данные панели. Главный администратор назначает и отзывает администраторов в разделе управления.

Посещения сохраняются в закрытой схеме БД. Функции `admin_dashboard` и `set_admin_role` проверяют роль в БД при каждом вызове; для них нет публичного обходного ключа. Отзыв прав блокирует следующий запрос к панели. Посещения считаются по случайному идентификатору вкладки; IP-адреса, email и URL-параметры не сохраняются. Для бесплатного тарифа Supabase проверьте текущие лимиты проекта в панели Supabase.

Готовые файлы для настройки: supabase/schema.sql, js/supabaseClient.js. При первом запуске замените два клиентских значения Supabase; остальные изменения ключей не требуют.
